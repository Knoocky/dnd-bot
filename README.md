# D&D Discord Bot

Discord-бот для ведения кампаний Dungeons & Dragons с AI Мастером Подземелий. Бот умеет работать через локальный `llama.cpp`, Claude API и GPT API, поддерживает автоматические мультиплеерные раунды, два режима бросков кампании и принимает команды как через префикс `!`, так и через упоминание в чате: `@бот команда`.

## Установка

```bash
pip install -r requirements.txt
copy .env.example .env
```

Заполни `.env` нужными ключами.

## Выбор AI-провайдера

Есть два способа выбрать, какое API использовать:

1. Через `.env`:

```env
AI_PROVIDER=local
```

или

```env
AI_PROVIDER=claude
```

или

```env
AI_PROVIDER=gpt
```

2. При запуске бота через аргумент командной строки:

```bash
python bot.py --provider local
python bot.py --provider claude
python bot.py --provider gpt
```

Аргумент `--provider` имеет приоритет над `AI_PROVIDER` из `.env`.

## Переменные окружения

Для локального `llama.cpp`:

```env
LLAMA_CPP_BASE_URL=http://127.0.0.1:8080/v1
LLAMA_CPP_MODEL=
LLAMA_CPP_API_KEY=local
```

Если `LLAMA_CPP_MODEL` пустой, бот автоматически берёт первую доступную модель из `/v1/models`.

Для Claude:

```env
ANTHROPIC_API_KEY=your_anthropic_key
ANTHROPIC_MODEL=claude-sonnet-4-20250514
```

Для GPT:

```env
OPENAI_API_KEY=your_openai_key
OPENAI_MODEL=gpt-5.2
```

Обязательные общие настройки:

```env
DISCORD_TOKEN=your_discord_token
BOT_PREFIX=!
```

## Примеры запуска

Локальная модель по умолчанию:

```bash
python bot.py
python bot.py --provider local
```

Claude:

```bash

```

GPT:


## Режимы бросков

После создания кампании бот попросит выбрать один из двух режимов:

- 1 - **бот бросает сам**: бот сам определяет необходимость проверки, сам кидает кубы и показывает результат перед ответом мастера.
- 2 - **игроки бросают сами**: бот просит конкретный бросок и ждёт результат в тексте действия, через `!бросок <итог>` или через `!бросок d20` / `!бросок д20`.

## Игровые справочники

Игровой контент для создания персонажей теперь вынесен в JSON-файлы:

- data/stats.json - характеристики
- data/races.json - расы, подрасы и их метаданные
- data/classes.json - классы, подклассы и стартовые параметры

Чтобы добавить новую расу, подрасу, класс или подкласс, достаточно отредактировать соответствующий JSON и перезапустить бота.

## Как вызывать команды

Поддерживаются оба формата:

```text
!команда аргументы
@бот команда аргументы
```

Примеры:

```text
!нк Тени над Брином
@бот начать_игру
!д осматриваю дверь и пытаюсь услышать, что за ней
@бот бр d20
```

```text
!сп
!р эльф
!пр лесной
!кл плут
!бн ловкость 2 мудрость 1
!им Лиара
!ос

!нк Подземелья Ржавого Холма
!ни
!д проверяю ловушку у сундука

@бот персонаж
@бот ин
@бот вз зелье лечения
```

## Что изменено

- Сохранены все существующие Discord-команды и игровая логика.
- AI-слой поддерживает `local (llama.cpp)`, `Claude` и `GPT` через единый интерфейс.
- Бот валидирует локальный сервер или нужный API-ключ при старте.
- Модель для каждого провайдера можно переопределить через `.env`.
- Команды можно вызывать и через `!`, и через упоминание бота.
- Для основных команд добавлены короткие алиасы длиной 1-3 символа.
- Для каждой кампании выбирается режим бросков: авто-броски ботом или ручные броски игроков с подтверждением.
- Расы, подрасы, классы и подклассы вынесены в JSON-справочники, которые можно пополнять без правки Python-кода.
- Создание персонажа работает как последовательный мастер: один активный черновик на канал, редактирование шагов теми же командами и таймаут 15 минут бездействия.

## Система прогресса

- XP теперь начисляется автоматически по итогам заметных сцен и значимых решений партии.
- Мастер может выдать дополнительный бонусный XP, если игроки особенно ярко проявили себя в эпизоде или продвинули важную сюжетную линию.
- В карточке персонажа всегда виден текущий уровень прогресса.
- Команда `!уровень` работает из любого состояния игры: она показывает XP, текущий уровень и сколько осталось до следующего повышения.
